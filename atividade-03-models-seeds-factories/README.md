# Atividade 03 – Models, Seeds e Factories no Laravel

**Desenvolvimento Web 2**

---

## Descrição

Nesta atividade aprofundei meus conhecimentos com o uso de **Models**, **Seeds** e **Factories** no Laravel, fundamentais para representar e popular as tabelas do banco de dados com dados reais e fictícios.  
Foi uma experiência enriquecedora, pois compreendi como os **Modelos Eloquent** representam as entidades do sistema, como criar e manter os **relacionamentos entre tabelas**, além de aprender a utilizar **factories** para geração em massa de dados de teste e **seeds** para dados fixos.

---

## Objetivos da Atividade

- Compreender o funcionamento dos **Models** como representação das tabelas no Laravel.
- Desenvolver relacionamentos entre as entidades: **Author**, **Book**, **Publisher** e **Category**.
- Criar e configurar **Factories** para geração de dados fake de autores, editoras e livros.
- Criar **Seeds** para popular a tabela de categorias com dados predefinidos.
- Utilizar **Laravel Artisan** para gerar os arquivos e popular o banco de dados.
- Automatizar testes e desenvolvimento com uso de milhares de registros fake.
- Consolidar a estrutura de um sistema de biblioteca completo e funcional.

---

## Pré-requisitos e Preparação do Ambiente

Assim como nas atividades anteriores, foi necessário garantir a preparação correta do ambiente de desenvolvimento para que tudo funcionasse como esperado.  
Essa etapa reforçou a importância de uma base sólida para evitar erros durante a criação e o povoamento do banco de dados.

### Requisitos

- **PHP** instalado.  
- **Composer** configurado (gerenciador de dependências do PHP).  
- **MySQL** em execução.  
- **Laravel** instalado no projeto.  
- **Git** configurado para versionamento.
