# Atividade 02 – CRUD com Laravel (MVC)  

**Desenvolvimento Web 2**  

---

## Descrição  

Nesta atividade desenvolvi um sistema completo de **cadastro de animes**, aplicando os princípios do **padrão MVC com Laravel**.  
Foi uma oportunidade prática para consolidar o uso de **Models**, **Controllers** e **Views** organizados de forma clara, além de reforçar o uso do **Eloquent ORM** como interface com o banco de dados.  

A interface foi construída manualmente com **HTML, CSS e JavaScript puros**, sem o uso de frameworks visuais. O foco da atividade foi estruturar corretamente o CRUD e compreender o papel de cada camada dentro de um projeto Laravel.

---

## Objetivos da Atividade  

- Criar migrations para estruturar o banco de dados de forma programada e versionada.  
- Aplicar corretamente o padrão **Model-View-Controller (MVC)** utilizando os recursos nativos do Laravel.  
- Utilizar o **Eloquent ORM** para realizar as operações de CRUD com segurança e simplicidade.  
- Construir as rotas RESTful com o comando **Route::resource()** 
- Desenvolver todos os métodos REST: index, create, store, show, edit, update, destroy.  
- Criar as views utilizando o motor de templates **Blade**, com HTML e CSS puro.  
- Implementar interações simples usando **JavaScript puro**, respeitando a leveza da aplicação.  
- Consolidar a separação de responsabilidades entre as camadas do Laravel.  

---

## Pré-requisitos e Preparação do Ambiente  

Antes de iniciar o desenvolvimento, foi necessário configurar o ambiente local para garantir o funcionamento adequado da aplicação.  
Esse processo reforçou a importância de uma preparação inicial sólida para evitar erros e retrabalho durante a codificação.

## Requisitos  

- **PHP** instalado.  
- **Composer** configurado (gerenciador de dependências do PHP).  
- **MySQL** em execução.  
- **Laravel** instalado corretamente no projeto.  
- **Git** configurado para versionamento.
